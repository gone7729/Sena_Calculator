# 공성 녹화 영상 → 시간 측정

1. `scan.py` — 영상 전체 프레임에서 턴 카운터·점수·아군 스킬 쿨 아이콘 10칸을 OCR(Tesseract), 값이 바뀌는 시각을
   `events.csv`(t, frame, region, value)로 기록. 영상 경로(`V`)와 좌표(`R`, 1920×1080 기준)는 스크립트 상단에서 수정.
   하단 아이콘 순서 = 진형번호 1~5(리나·지크·비스킷·미호·나타). 아이콘 위/아래가 어느 스킬인지는 영웅마다 다름
   (나타: 위 = 혼천릉파(2스킬), 아래 = 화첨창술(1스킬)).
2. `clock.py` — 평타 쿨감을 받지 않는 쿨(비스킷 장비강화·리나 울림)을 이어 붙여 연속 게임 시계 G(t)를 만들고,
   턴 시작 시각(부분 판독 허용)마다 게임 경과를 출력. 체인 시작 시각·값은 영상에 맞게 수정.
3. 시뮬과 비교: `dotnet run --project tools/PracticeTest -- tools/PracticeTest/team.json 월요일 나타 6 replay videoplan`
   → `results/practice/ledger_video.csv`(시뮬 시간 장부)와 같은 구간끼리 비교.

규칙(2026-10 녹화로 확정): 쿨 표시 = 소수점 버림 / 평타·1스킬 모션 중 실시간 감소 / 2스킬 컷신 중 정지 후 4 일괄 감소 /
라운드 전환은 사망연출 1초만 흐르고 나머지 정지 / 자기 스킬 쿨은 시전 완료 후부터.

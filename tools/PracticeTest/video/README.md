# 공성 녹화 영상 → 시간 측정

1. `scan.py` — 영상 전체 프레임에서 턴 카운터·점수·아군 스킬 쿨 아이콘 10칸을 OCR(Tesseract), 값이 바뀌는 시각을
   `events.csv`(t, frame, region, value)로 기록. 영상 경로(`V`)와 좌표(`R`, 1920×1080 기준)는 스크립트 상단에서 수정.
   하단 아이콘 순서 = 진형번호 1~5(리나·지크·비스킷·미호·나타). 아이콘 위/아래가 어느 스킬인지는 영웅마다 다름
   (나타: 위 = 혼천릉파(2스킬), 아래 = 화첨창술(1스킬)).
2. `clock.py` — 평타 쿨감을 받지 않는 쿨(비스킷 장비강화·리나 울림)을 이어 붙여 연속 게임 시계 G(t)를 만들고,
   턴 시작 시각(부분 판독 허용)마다 게임 경과를 출력. 체인 시작 시각·값은 영상에 맞게 수정.
3. 시뮬과 비교: `dotnet run --project tools/PracticeTest -- tools/PracticeTest/team.json 월요일 나타 6 replay videoplan`
   → `results/practice/ledger_video.csv`(시뮬 시간 장부)와 같은 구간끼리 비교.

규칙(2026-10 녹화로 확정): 쿨 표시 = 소수점 버림 / 평타·1스킬 모션 중 실시간 감소 / 2스킬 컷신 중 정지 후 4 일괄 감소 /
라운드 전환은 사망연출 1초만 흐르고 나머지 정지 / 자기 스킬 쿨은 시전 완료 후부터.

## 게임 시계로 행동 소요시간 측정 (2026-11 수요일 녹화)

1. `scan_clock.py <영상> <출력csv> [시작초] [끝초] [아군칸]` — 0.1초 간격으로 턴 카운터 + **보스 스킬 쿨 2칸**(보스 초상 오른쪽
   1·2번째 칸) + 평타 쿨감을 안 받는 아군 쿨 칸(기본 비스킷·리나)을 판독. 창 모드 녹화 좌표 기준(진형 1~5 = 라이언·리나·비스킷·미호·나타).
2. `clock_fit.py <clock.csv> <시뮬 ledger.csv> [출력csv]` — 카운터별 감소 런 → 1초 감소 순간을 앵커로, 시간이 겹치는 런끼리
   오프셋을 맞춰 하나의 게임 시계 G(t)로 이어 붙이고(고립 오독 제거), 턴 시작마다 게임 경과 vs 시뮬 경과·누적차 출력.
3. 시뮬 장부: `dotnet run --project tools/PracticeTest -- tools/PracticeTest/team_wed.json 수요일 나타 6 replay wedplan`
   → `results/practice/ledger_wed.csv`. 시간 인자: `basic= a1= a2= e1= e2=`(초) · `estart`/`eend`(적 스킬 턴시작 판정 on/off) · `seed=`.

결과(`results/practice/clock_cmp_wed.txt`): 턴 구성별 최소제곱 → 평타 1.85 · 아군 1스킬 3.27 · 아군 2스킬 4.24 · 적 1스킬 3.09초,
적 스킬 사용 여부는 턴 시작(평타 前) 쿨로 판정. → `SiegeBattleConfig` 기본값으로 반영(SYSTEM.md 8.2).

## 버프/디버프 아이콘 사전

`icons.py <영상> [출력폴더] [프레임간격]` — 영상 전체에서 유닛 머리 위·적 HP바 옆·보스 상단의 아이콘을 잘라 종류별로 묶는다.
`icons/` = 월요일 녹화에서 뽑은 결과: `tmpl/<id>.png`(27×27 대표), `icons.csv`(횟수·처음/마지막 시각·위치·추정·라벨), `sheet.png`(확대 목록).
종류: P = 상시 버프(파란 바탕, 숫자 없음) / T = 턴제 버프(어두운 바탕 + 남은 턴) / DP = 상시 디버프 / DT = 턴제 디버프.
`icons.csv`의 `label` 칸에 실제 효과명을 채우면 사전 완성 → 다음 단계(유닛별 아이콘 변화 = 버프/디버프 이벤트 추출)에서 템플릿으로 사용.
주의: `icons/`는 자동 추출(50종) 뒤 컷신·데미지 숫자에 가려진 조각을 손으로 합쳐 23종으로 정리한 것이라, `icons.py`를 다시 돌리면 조각이 더 많이 나온다.
`guess` 칸은 처음 보인 시각과 시뮬 로그 시전 시점을 맞춰 본 추정(미확인).

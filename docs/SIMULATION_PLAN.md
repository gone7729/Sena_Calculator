# 세나리 시뮬레이터 구현 계획

전투 시뮬레이션 기반 **최적 팀 + 템세팅 탐색** 기능의 전체 계획. 우선 **공성전(토요일)** 부터 구현한다.
(상세 규칙·수치는 세션 메모리 `simulator_optimizer_plan` / `siege_simulation_rules` / `battle_time_model` 에 박제됨)

---

## 1. 최종 목표

유저가 컨텐츠·영웅(5~8명, 초월 단계)·펫(잠재능력)을 고르고 **탐색**을 누르면:
- 진형 3종(보호/밸런스/기본)을 순회하며 **영웅 조합 전수탐색** + 영웅별 장비 최적화 + 시뮬
- **가장 높은 데미지를 낸 팀 1개**(정배)를 그 진형·영웅·턴별 행동과 함께 제시
- 동일 팀에 대해 **템세팅 2종** 제시:
  - **안정형** — 치확·약확 100% 확보 제약 하 최적 (운에 안 기댐)
  - **고점형** — 실제 치확 c%·약확 w% 반영한 **기댓값 데미지** 최대 (best-case 아님 — 운빨 세팅 배제)
- 기댓값은 해석적 계산(몬테카를로 불필요): `E[치명계수]=1+c·(치피/100−1)`, `E[약점계수]=1+w·(약피/100−1)`, 가산항은 c·/w· 가중

전수탐색 현실화: 등장 영웅이 8명뿐이므로 **장비 최적화를 (영웅×진형) 단위로 캐싱** → 8×3=24회 최적화 + 팀별 시뮬만.

## 2. 확정된 것 (2026-05)

### 데이터 (토요일 공성전)
- **보스/잡몹 스탯·감쇄** — `EnemyDb.SiegeBosses`(스파이크 등 7요일 보스), `EnemyDb.SiegeMobs`(룩·챈슬러, 라운드별 별도 Id 501~506)
- **보스/몹 스킬** — `SiegeBossSkillDb`(보스는 이름 기반, 몹은 `MobSkillsById` Id 기반)
- **라운드 구성** — `EnemyDb.SiegeStages["토요일"]`(Stage.Waves = R1~R3, R3는 `StageEnemy.IsBoss=true`)
- **적 스킬 우선순위** — `StageWave.SkillPriority` (순위; 쿨 충족된 것 중 최고 순위 사용)
- **공성전 감쇄** — 룩·챈슬러도 스파이크와 동일(마법90/1인70/5인90), `EnemyDb` 정적 생성자에서 부여

### 시간 모델 (`battle_time_model`)
- 정수 초 단위. **쿨다운 = 실시간 1초당 1 감소** (= 행동 소요시간만큼 모든 쿨 감소)
- 평타 **2초** / 1스킬 **4초** / 2스킬(컷신) **5초** / DoT **1초**(있을 때만) / 스킬턴(0턴) **0초**
- ⚠ 기존 `Skill.GetActionDuration`은 모든 스킬 4초 → 2스킬(컷신) 5초 보정 필요

### 전투 규칙 (`siege_simulation_rules`)
- **70턴 누적 데미지 = 공성전 점수**. 적군은 **HP 0이어도 죽지 않음**
- 70턴은 R1부터 연속 경과, 라운드 전환 시 턴 이어짐. 라운드 진입 턴은 **0턴(스킬턴)**, 턴 미소모
- **선공** = 팀 총 속공치(합) 높은 팀, 같으면 랜덤
- **행동(기본공격, 턴 소모) 순서** = 속공 내림차순, 동속공이면 자리번호 낮은 영웅 먼저
- **약점 타겟** = 최저 HP 적, 동률이면 앞열 우선. **R3는 항상 보스**
- 적 턴제 버프는 아군 버프 해제로 제거 가능

## 3. 작업 계획 — 공성전 시뮬 엔진 (로컬에서 하나씩 검토)

기존 `BattleSimulator`(단일 보스전)와 별개로 공성전 전용 흐름이 필요. 단계별로:

1. **상태 모델** — 다중 적(라운드별 여러 적) + 라운드/턴/스킬턴 상태. 적 HP0 무사망·보스취급(IsBoss) 플래그 반영
2. **턴 진행 루프** — 선공 결정(팀속공합, 동률 랜덤) → 스킬턴(0턴, 미소모) → 기본공격(속공순·동속공 자리순) → 70턴까지, 라운드 전환(턴 이어짐)
3. **타겟팅** — 약점=최저HP/동률 앞열, R3는 보스. 일반 공격 대상 선정
4. **적 행동** — `SkillPriority` 소비(쿨 충족 최고 순위) + 쿨다운(초, 행동 소요시간만큼 감소)
5. **점수 집계** — 70턴 누적 데미지 = 점수. 라운드별·캐릭별 기여 로그

> 각 단계는 로컬 세션에서 구현 → 검토 → 다음 단계 순으로 진행.

---

## 4. 이후 단계 (공성전 엔진 완성 후)

6. **옵티마이저 시뮬 기반 전환** — 현재 단일딜(DamageCalculator) 평가 → 시뮬(BattleSimulator) 기반. (영웅×진형) 캐싱
7. **영웅 조합 전수탐색** — 후보 5~8명 중 5명 조합 × 진형 3종. 고정 슬롯(필수 버퍼·면역·디버퍼) 활용
8. **스킬순서 자동탐색** — `RotationMode.AutoOptimize` 스텁 구현
9. **템세팅 2종** — 안정형(치확/약확 100% 제약) + 고점형(기댓값 최대)
10. **웹 포팅** — Next.js/Vercel + Web Worker

## 5. 미반영 / 후속 (모델 부재 → 보스 행동 구현 시 처리)

- **광폭화** (전 보스 공통, 턴 경과 피증: 30턴 +50% → 40/50/55/60턴 단계 상승)
- **반격**(제이브 25%), **적군 사망 시 피해 무효화**(델론즈), **자기 보호막**(루디)
- **혹한의 기운/숨결** (R3 챈슬러 → 스파이크 강화), **빙결 해제 폭발**(스파이크)
- 기존 코드 **"상대 스킬 사용 시 내 쿨 −5초"** 로직 — 공성전 적용 여부 검증
- 룩 혹한의 일격 "동일 열 추가 타격" 등 열(row) 기반 타겟

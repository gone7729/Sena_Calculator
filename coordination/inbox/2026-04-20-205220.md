## 요청 내용

현재 DB 데이터(C# `DB/*.cs`)를 활용해 웹에서 다음 기능을 제공하는 앱을 신규 구축한다:

1. **캐릭터 정보 열람** — `CharacterDB` 기반 (스킬/패시브/스탯 표시)
2. **장비/장신구/펫 데이터 열람** — `EquipmentDB`, `PetDB` 등
3. **영웅별 템 추천** — 캐릭터 특성에 맞는 장비 세트/메인옵/서브옵 가이드
4. **던전(보스)별 영웅 추천** — `EnemyDB` 보스 정보 기반 카운터 픽
5. **턴제 최적화 빌드** — 기존 `EquipmentOptimizer` + `BattleSimulator` 로직을 웹으로 이전

## 기술 스택 (확정)

- **프레임워크**: Next.js (React)
- **배포**: Vercel
- **언어**: TypeScript (권장)
- **데이터 레이어**: JSON 정적 파일 (DB 없음)

## 확정 결정 (op 사전 결정)

- **데이터 저장**: **JSON-only** (Supabase/DB 없음)
  - 이유: 게임 데이터는 정적(패치 시에만 갱신), 로그인 필요 기능 없음, Vercel CDN 캐싱 활용
  - 향후 user-specific 기능(프리셋 저장, 즐겨찾기, 빌드 공유) 필요 시 Supabase 추가 검토
- **DB 데이터 이전 전략**: **(a) C# DB 클래스 → JSON 자동 export 스크립트**
  - 기존 WPF 계산기와 데이터 정합성 유지
  - 대안 (b) 수기 TS 마이그레이션, (c) .NET API Route는 **제외**

## 결정 필요 (head plan 단계에서 재확인)

- **계산 엔진 (DamageCalculator / BattleSimulator / EquipmentOptimizer) 포팅 범위**:
  - MVP: 정보 열람 + 단순 추천만 (계산 엔진 제외)
  - Full: 시뮬레이터/옵티마이저까지 TS 포팅
  → 단계별 진행 권장 (MVP → 점진 확장)

- 기존 WPF 계산기는 **유지** (병행 운영). 웹 앱은 별도 디렉토리(예: `web/`) 또는 별도 repo 분리 검토.
- 데이터 정합성: WPF 계산기와 웹 앱이 동일한 DB 정보를 사용해야 함.
